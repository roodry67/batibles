Batibles \- Log maestro cronológico de sesiones

Estado: versión v0.2 revisada tras corregir Arcos 0, 1, 2 y 3\.  
Objetivo: servir como columna vertebral del futuro vault de Obsidian.  
Uso previsto: cada entrada de este documento debe poder convertirse después en una nota individual dentro de 02\_Sesiones.

Criterio de uso

Este documento organiza la campaña por sesiones reales, no por arcos narrativos. Cada sesión incluye fecha real, fecha o fechas in-game, arco, lugares principales, acontecimientos, información obtenida y tramas actualizadas.

Cuando una sesión no tiene información suficiente, se marca como incompleta. Cuando un acontecimiento se conoce pero no puede asignarse con precisión a una sola sesión, se coloca en el bloque más probable y se marca como asignación aproximada.

Reglas de lectura

\- Información confirmada: se redacta como hecho.  
\- Hipótesis del grupo: se marca como hipótesis.  
\- Duda de grafía o fecha: se conserva como duda.  
\- Los nombres entre dobles corchetes están preparados para Obsidian.
