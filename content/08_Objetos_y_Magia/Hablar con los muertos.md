# Hablar con los muertos

## Resumen

Conjuro usado por el grupo para obtener información de cadáveres.

## Informacion confirmada

- En la trama de [[Kazar]], el grupo usa o planea usar este conjuro para interrogar al cadáver del [[Clérigo de Kazar]].
- El cadáver se conserva con [[ungüento de eternidad]] para poder repetir la consulta con el tiempo.
- El conjuro solo puede usarse una vez por semana con una misma persona.
- Esta vía es relevante para [[Firkraag]], porque el ritual del clérigo parecía apuntar a conocimientos útiles sobre almas.
